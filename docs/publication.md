# Подготовка публичной поставки

Эта поставка продолжает отдельный `delm-board`. Основная доска `pi-durable-delm` остаётся на своём новом хосте; эта работа её не переносит и не заменяет. Пользователь явно разрешил повторную проверку, новый README, схему, промпты и смену видимости только `Diffuzmetall/delm-board` на public.

## Область изменений

- Русский README с двумя разными путями: настоящий Durable SDK и обычный Pi CLI.
- `AGENTS.md` и переносимые запросы агенту-установщику и участнику.
- Архитектурные Mermaid-схемы, отдельная SDK-инструкция.
- Включение этих материалов и сохранённых отчётов в runtime-архив.
- Проверка ссылок/пакета и новый прогон тестов перед открытием репозитория.

Поведение `adapters/`, `bin/` и `board/` не меняется относительно `36f3b15`. Проверенная публичная версия зависимостей остаётся 1.4.0. Результаты предыдущей приватной приёмки в `docs/evidence/` относятся к указанным там кандидатам; они не переименовываются в проверку новой поставки.

## Результаты повторной проверки

- Core: 34/34 PASS; публичный Durable SDK: 9/9 PASS; Pi lifecycle и загрузка без привязки: 7/7 PASS.
- Настоящий npm Pi CLI/RPC: PASS, включая wait → событие → follow-up → snapshot/read/ACK → новое ожидание. Использовано 17 запросов локальной детерминированной модели.
- Свежая упаковка и отдельная установка своих зависимостей: PASS. SDK factory и тот же реальный CLI/RPC проходят из установленного архива, без private/source-lane импорта.
- Относительные файловые ссылки проверены в Git-дереве и npm-архиве. Все три Mermaid-схемы прошли настоящий синтаксический parser. Художественная генерация картинок не использовалась.
- Промпты сверены с исходным CLI и контрактами адаптеров для SDK, Pi CLI, board-only и неизвестного хоста. Это source review, не обещание правильного поведения любой модели.
- История Git и публикуемый набор файлов проверяются на известные шаблоны ключей, приватные пути, RUN/session databases и generated files. Публикуемые Git identities используют noreply. Это ограниченная проверка утечек, не полный security audit.

Среда: Node 24.19.0, Python 3.13.7. Минимальные версии, Windows и произвольное приложение друга не проверены. Живые внешние модели не вызывались; SDK использует детерминированный fixture, RPC — loopback provider. Унаследованные SQLite ResourceWarning в core-тестах нефатальны и не устранены этой документационной поставкой.

Машиночитаемая запись: [evidence/publication.json](evidence/publication.json). Старые доказательства сохраняют свою исходную область. Свежую публичную доступность подтверждает отдельная проверка GitHub после push и смены visibility; один локальный тест этого не доказывает.

RUN, токены, сессии и сырые приватные логи в поставку не входят. Публичная точка входа: https://github.com/Diffuzmetall/delm-board.
